# منصة المهارات الرقمية الذكية

نسخة أولية (v0.1): الصف الرابع — الوحدة الأولى — الدرس الأول «الحاسب» مكتمل التفاعل. باقي الدروس موجودة في خريطة المنهج (`src/data/curriculum.json`) وتظهر «قيد الإعداد» حتى تُضاف ملفات محتواها.

## التشغيل محليًا
```
npm install
npm run dev
```
## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد إلى الفرع `main`.
2. من Settings ← Pages اختر Source: **GitHub Actions**.
3. بعد كل push يبني `.github/workflows/deploy.yml` الموقع وينشره على `https://اسمك.github.io/اسم-المستودع/`.

## إضافة درس جديد
1. أنشئ `src/data/lessons/<معرّف-الدرس>.json` بنفس بنية `g4-u1-l1.json` (المعرّفات في `curriculum.json`).
2. سجّله في الخريطة `lessons` أعلى `src/App.tsx`.

## الخصوصية
لا تُجمع بيانات شخصية؛ يُحفظ التقدم في المتصفح فقط (LocalStorage) مع تصدير/استيراد للنقل بين الأجهزة.
